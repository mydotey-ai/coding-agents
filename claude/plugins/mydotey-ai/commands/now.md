# now

总结当前会话的整体状态，帮助用户快速了解「我在做什么」「做到哪了」「还剩什么」。

## 执行步骤

1. **回顾原始任务**
   - 回顾对话历史，提取用户最初的任务请求和核心目标
   - 如果有多轮任务，按时间顺序列出每个阶段的主题

2. **回顾已完成的工作**
   - 列出已修改/创建的文件及其改动目的
   - 列出已执行的关键命令及其结果
   - 如果使用了 task list，列出已完成的 task

3. **识别当前进展**
   - 正在做什么（当前任务或最近的操作）
   - 当前是否有未完成的 task list，标记未完成的 item
   - 检查是否有未暂存的 git 改动、未提交的文件

4. **列出待完成的工作**
   - 对比初始目标与当前进展，列出剩余步骤
   - 标记是否有阻塞项或待决策的问题

5. **输出格式**
   - 用简洁的分段格式输出，每段带小标题
   - 优先用列表，不要大段文字
   - 不要在总结中添加新的分析或建议，只描述状态

## 注意事项

- 这是一个**只读**命令，不执行任何修改操作
- 输出应该紧凑，控制在 30 行以内
- 如果用户没有明确的任务，只显示当前 git 状态和最近的对话主题即可
- 不要重复完整对话，只提炼关键结论和状态
